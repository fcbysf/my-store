# Crochet Maker storefront

Home and Shop use the [Nativity Set page](https://crochetmaker.pocketsflow.com/6af760796090c2dfad20ec6f) as their visual reference. The November 22, 2026 capture shows a cream page, warm brown controls, fine dividers and large product photography.

| Role | Storefront treatment |
| --- | --- |
| Page | Cream `#FAF7F2`, sampled from the reference page styles |
| Headings and body | Dark brown `#3D2C1E` and `#54432F` |
| Primary actions | Brown `#8A6D4A`, rounded 10 px corners |
| Typography | Locally hosted Playfair Display for headings and Inter for body text |
| Secondary surfaces | Warm neutral `#F1EAE0` and border `#DFD6CA`, chosen for the catalog and footer |

The Home carousel and Shop grid use the patterns’ own cover images. Cards and search results open the corresponding Pocketsflow listing in the same tab.
